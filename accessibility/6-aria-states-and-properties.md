# Accessibility Feature 6 - ARIA States and Properties

Defensive accessibility implementation checklist.

- Use semantic HTML whenever possible.
- Provide an equivalent accessible interaction.
- Test keyboard operation and visible focus.
- Test with a screen reader where appropriate.
- Do not rely on color alone to communicate state.
- Verify responsive behavior and readable text.

Review this implementation against the applicable WCAG level and the application's legal/accessibility requirements.
